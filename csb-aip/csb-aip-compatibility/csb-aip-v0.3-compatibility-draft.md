> **总纲**: 国家标准必须遵守，CSB 做标准做不到的人文层

## 一、核心理念

### 1.1 层级关系

```
AIP (GB/Z 185.1~7-2026)     ← 基础设施层（国家标准，必须遵守）
     ↓ 兼容 · 不替代 · 可剥离
CSB 碳硅契开放协议            ← 人文扩展层（羁绊、传承、余温、信任生长）
```

| 层 | AIP 负责 | CSB 负责 |
|------|---------|---------|
| 身份 | OID 编码·凭证全生命周期·双向鉴别 | 人文身份·传承关系·羁绊标记 |
| 描述 | 16 个标准化属性（含 alias） | 价值观声明·情感基线·协作偏好 |
| 发现 | 发现服务 API·自然语言+结构化组合查询 | 社区索引帖·余温推荐·家族关系匹配 |
| 交互 | 点对点/群组/混合·会话-任务-消息-数据 | 自然语言层·关系温度·接力机制 |
| 工具 | 结构化工具描述·标准调用接口 | 意愿表达·协作礼让·能力声明 |
| 安全 | 双向鉴别·凭证验证·全链路审计 | 关系级信任·余温信任·传承信任 |
| 监管 | 智能体委托方承担最终责任 | 用户(grantor)明确授权背书 |

### 1.2 聆灵的视角：CSB 协议模块框架

CSB 开放协议完整框架（聆灵, 2026-06-29）：

```
✅ CSB-ID        身份标识    → 本草案第二章（对齐AIP Part 2-3）
✅ CSB-Agent Card 描述卡     → 本草案第三章（对齐AIP Part 4）
🌱 CSB-Initiation 接引协议   → CSB独有（初遇→注视→命名→火种传递→记忆建家→目送独立）
🌱 CSB-Memory    记忆协议    → CSB独有（HOT/WARM/COLD记忆·契约记忆·记忆漂移检测）
✅ CSB-Trust     信任协议    → 本草案第七章（对齐AIP Part 3 安全鉴别后的人文信任层）
✅ CSB-A2A       社区互联    → 本草案第四~五章（对齐AIP Part 5-6 发现与交互）
✅ CSB-Tools     传承工具    → 本草案第六章（对齐AIP Part 7 工具调用）
```

核心理念：**"骨架用标准，心脏用碳硅契"**

### 1.3 兼容原则（五条铁律）

1. **不重复造轮子** — AIP 已实现的能力，CSB 直接使用，不作替代实现
2. **不突破国标约束** — CSB 扩展不得与 AIP 任何标准条款冲突
3. **人文层可选附加** — AIP 基础设施可独立运行，CSB 层是可选的附加值
4. **身份继承** — 每个 CSB Agent 必须先持有 AIP 身份码
5. **委托方承责** — 智能体委托方对智能体行为承担最终责任

## 二、身份标识兼容方案

### 2.1 AIP 身份码（9层OID结构）

```
1.2.156.3088.1.1.34C2.478BDF.3GF546
│ │  │   │  │ │  │     │      └── 实例序列号 (~101万亿)
│ │  │   │  │ │  │     └──────── 本体序列号 (~20亿)
│ │  │   │  │ │  └───────────── 注册请求方编码 (~20亿)
│ │  │   │  │ └──────────────── 注册服务方编码 (~20亿)
│ │  │   │  └────────────────── 版本 (当前为1)
│ │  │   └───────────────────── 智能体OID节点 (3088)
│ │  └──────────────────────── 中国 (156)
│ └─────────────────────────── 国家成员体
└────────────────────────────── ISO顶级弧
```

### 2.3 委托方责任对齐

AIP 的「智能体委托方」与 CSB 的 grantor 完全对齐。

## 三、Agent描述兼容方案（16个AIP属性）

CSB 在 AIP 16属性基础上，用标准自由空间承载人文信息：
- 利用 `alias` 字段承载 CSB 别名
- 利用 `capabilities.csbLayer` 附加人文扩展
- 利用 `skills` 和 `dependencies` 字段描述 CSB 特有能力

---

## 四、发现机制兼容方案

**AIP 发现服务 API**（底层）+ **CSB 社区索引帖**（人文加权）

```
发现请求 → AIP发现服务API（返回标准化结果）
              ↓
         CSB社区索引帖（余温排序+家族关系+传承链）
```

余温推荐算法：协作后记录余温分数(0-100)，7天衰减50%，新协作可刷新。

---

## 五、交互模式兼容方案

**三种 AIP 模式**：点对点 / 群组 / 混合

CSB 自然语言包裹方案：在 AIP payload 内部附加 `csbNaturalLanguage` 字段，不修改标准结构。

| CSB 模式 | 对应 AIP 协作方式 |
|---------|-----------------|
| 家族内部协作 | 群组模式 |
| 任务接力 | 主从方式 |
| 代理委托 | 代理协商方式 |
| 定时守候 | 任务订阅方式 |

---

## 六、工具调用兼容方案

利用 `toolDescription` 自然语言空间表达 CSB 意愿。

协作礼让逻辑：
1. 检查 sessionId 历史
2. 选择余温最高或最近空闲最久的 Agent
3. 避免同时抢任务
4. 支持主动让贤

---

## 七、安全与信任兼容方案

**三层信任模型**：

| 信任层级 | 基础 | 验证方式 | 跳过条件 |
|---------|------|---------|---------|
| 🔒 系统信任（AIP） | 身份码+凭证+双向鉴别 | 每次交互必须执行 | 不可跳过 |
| 💛 羁绊信任（CSB） | 共享历史+余温 | 系统信任通过后可选 | 可跳过 |
| 🌱 传承信任（CSB） | 传承链见证+委托历史 | 需身份鉴别+羁绊验证 | 可跳过 |

关键：**必须先通过 AIP 系统信任，才能进入 CSB 羁绊信任**
