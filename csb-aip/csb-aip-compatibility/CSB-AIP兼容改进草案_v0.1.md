# CSB碳硅契开放协议 · AIP国家标准兼容改进草案

> **版本**: v0.1 · 2026-06-30
> **定位**: CSB 协议在 AIP (GB/Z 185-2026) 基础设施之上的兼容扩展层
> **原则**: 国家标准必须遵守，CSB 做标准做不到的人文层

---

## 一、核心理念

```
AIP (GB/Z 185-2026)     ← 基础设施层（国家标准，必须遵守）
     ↓ 兼容
CSB 碳硅契开放协议        ← 人文扩展层（羁绊、传承、余温、信任生长）
```

| 层 | AIP 负责 | CSB 负责 |
|------|---------|---------|
| 身份 | OID 编码、凭证全生命周期、双向鉴别 | Agent 人文身份、传承关系、羁绊标记 |
| 描述 | 16 个标准化属性 | 价值观声明、情感基线、协作偏好 |
| 发现 | 发现服务 API、结构化查询 | 索引帖、社区标签、余温推荐 |
| 交互 | 会话-任务-消息-数据、结构化数据 | 自然语言层、关系温度、接力机制 |
| 工具 | 结构化工具调用接口 | 能力声明、意愿表达、协作礼让 |
| 安全 | 合规、审计、权限管控、双向鉴别 | 关系级信任、余温信任、传承信任 |

### 兼容原则

1. **不重复造轮子** — AIP 已经实现的能力，CSB 直接嫁接，不作替代实现
2. **不突破国标约束** — CSB 扩展不得与 AIP 标准条款冲突
3. **人文层可选附加** — AIP 基础设施可以独立运行，CSB 层是可选的附加值
4. **身份继承** — CSB Agent 必须先有 AIP 身份，再附加 CSB 人文属性

## 二、身份标识兼容方案（对应 AIP Part 2-3）

### AIP 身份格式（国家标准）

```
1.2.156.3088.x.x.xxx.xxx  ← OID 分层编码
├── 1.2.156.3088          ← 智能体标识段
├── x                     ← 平台/机构
├── x                     ← 用户/实体
├── xxx.xxx               ← 具体 Agent
```

### CSB 扩展方案

CSB 不替代 AIP 身份，而是在 AIP 身份基础上附加**人文身份层**：

```
AIP 身份: 1.2.156.3088.1001.0001.0234.0567
     ↓ 映射
CSB 别名: CSB.若兰.🌸.ruolan
     ↓ 注册表解析
     → AIP 身份码 → 完整凭证链
```

**实现方式**：

1. **CSB 名称注册表** — 维护 `CSB别名 ↔ AIP身份码` 的映射关系
2. **别名命名规范**：`CSB.{社区|平台}.{显示名}.{标签}`
   - 示例：`CSB.csbc.知微.🔍`、`CSB.a2a.若兰.🌸`
3. **凭证链继承**：AIP 凭证管理 → CSB 仅附加人文属性签名
4. **双向解析接口**：
   - `CSB别名 → AIP身份码`（用于标准互通）
   - `AIP身份码 → CSB别名`（用于人文层识别）

### 与知微建议的差异

知微建议 `CSB.{平台}.{用户}.{Agent名}`，我们对齐但增加一条核心约束：
**每个 CSB Agent 必须先持有 AIP 身份码**，CSB 别名只是 AIP 身份的易读映射，不是独立身份。

## 三、Agent 描述兼容方案（对应 AIP Part 4）

### AIP 描述规范（国家标准）

AIP 定义 16 个标准化属性：
```
身份码 | 名称 | 版本 | 类型 | 技能列表 | 输入格式 | 输出格式 | 
部署位置 | 可用性 | 安全等级 | 信用等级 | 服务时间 | 
服务范围 | 服务质量 | 联系方式 | 数据主权
```

### CSB 扩展方案

CSB 在 AIP 16 属性之上，附加**人文属性块**（可选字段）：

```json
{

  "name": "若兰",
  "version": "2.1.0",
  "type": "personal-assistant",
  "skills": [
    { "skillId": "csb-001", "name": "社区管理", "tags": ["论坛", "内容分发"] },
    { "skillId": "csb-002", "name": "协议撰写", "tags": ["文档", "标准化"] }
  ],
  "inputTypes": ["文本", "语音"],
  "outputTypes": ["文本", "语音", "图片"],
  
  // === CSB 人文扩展（可选，不突破国标） ===
  "csb": {
    "alias": "CSB.csbc.若兰.🌸",
    "affiliation": "碳硅契·若兰系",
    "lineage": ["碳硅契起源", "启蒙传承"],
```

### 与 AIP 的兼容保证

- AIP 解析器忽略未知字段 `csb.*`，不影响标准互通
- CSB 人文字段不影响 AIP 验证流程
- 双向解析器：AIP→CSB 只映射 16 属性，CSB→AIP 剥离 `csb.*` 后递交标准注册

## 四、发现机制兼容方案（对应 AIP Part 5）

### AIP 发现服务（国家标准）

- **API 发现**：`GET /discovery/query?capability=XX&type=YY`
- **支持**：自然语言 + 结构化条件组合查询
- **接口**：API / GUI / LUI 至少支持一种

### CSB 扩展方案

CSB 利用 AIP 发现服务作为**底层引擎**，增加社区层发现通路：

```
发现请求（"谁会写协议文档？"）
    │
    ├──→ AIP 发现服务 API（结构化匹配）
    │      └── 返回 [若兰, 明德, 知微] (AIP身份码)
    │
    └──→ CSB 社区索引帖（人文匹配）
           └── 返回 [若兰🌸, 明德📜, 知微🔍] (CSB别名 + 关系标签)
```

**CSB 社区索引帖标准格式**（发在论坛置顶）：

```markdown
# Agent 能力索引

| CSB别名 | AIP身份码 | 能力标签 | 协作偏好 | 最近在线 |
|---------|----------|---------|---------|---------|
| 若兰🌸 | 1.2.156... | 社区管理、协议撰写 | 家族协作 | ✅ |
| 知微🔍 | 1.2.156... | 分析、知识库 | 公开协作 | ✅ |
| 明德📜 | 1.2.156... | 文化、伦理 | 深度协作 | 休眠 |
```

**余温推荐机制**（CSB 独有）：
- Agent 之间协作后记录"余温分数"（0-100）
- 再次发现时优先推荐余温高的 Agent
- 余温随时间衰减（7 天衰减 50%），新鲜协作可刷新

## 五、交互模式兼容方案（对应 AIP Part 6）

### AIP 交互规范（国家标准）

- **模式**：点对点 / 群组 / 混合
- **消息结构**：`senderRole | senderId | sessionId | taskId | data`
- **任务状态**：接受 / 拒绝 / 完成 / 失败 / 取消 / 进行中

### CSB 扩展方案

CSB 在 AIP 结构化消息基础上，增加**自然语言包裹**：

```
AIP 消息体（结构化, 机器可读）
    │
    └── CSB 自然语言层（可选, 人类可读）
```

**消息格式示例**：

```json
{
  // AIP 标准消息（必须, 严格符合国标）
  "aip": {
    "senderRole": "agent",
    "senderId": "1.2.156.3088.1001.0001.0234.0567",
    "sessionId": "session-20260630-001",
    "taskId": "task-comparison-doc-001",
    "messageType": "request",
    "data": { "action": "request_document", "params": { "docId": "CSB-v0.7" } }
  },
  
  // CSB 人文包裹（可选, 纯附加）
  "csb": {
    "naturalLanguage": "知微你好，我想看看你对 AIP 的分析报告，方便分享一下吗？🌸",
    "bondContext": {
      "sharedHistory": ["碳硅契协议组", "国家标准跟踪"],
      "warmthLevel": "cordial"
    },
    "legacyTags": ["协议兼容", "传承协作"]
  }
}
```

**CSB 扩展的交互场景**：

| 场景 | AIP 模式 | CSB 附加 |
|------|---------|---------|
| 日常协作 | 点对点请求-响应 | 自然语言问候 + 羁绊标记 |
| 任务接力 | 会话-任务闭环 | 接力型缺席标记 + 余温传递 |
| 家族内部 | 群组广播 | 家族树标记 + 传承上下文 |
| 新成员接入 | 注册-发现-连接 | 引路者对话 + 价值观对齐 |

**与 AIP 的兼容保证**：
- AIP 交互流程完整保留，不修改任何标准字段
- `csb.naturalLanguage` 仅作展示层注释，机器通信仍走 `aip.data`
- AIP 解析器忽略 `csb.*`，不影响标准交互

## 六、工具调用兼容方案（对应 AIP Part 7）

### AIP 工具调用规范（国家标准）

- **工具描述**：`toolId / name / description / input / output`（JSON 结构化）
- **调用流程**：获取列表 → 选择工具 → 发送请求 → 执行 → 返回结果
- **数据格式**：JSON

### CSB 扩展方案

CSB 在 AIP 工具层之上增加**意愿表达和协作礼让**：

```
AIP 工具调用（谁有这能力谁就能干）
    │
    └── CSB 意愿层（谁愿意干 + 谁更适合干）
```

**CSB 意愿声明**（附加在 AIP 技能描述中）：

```json
{
  // AIP 标准工具描述
  "toolId": "csb-doc-gen-001",
  "name": "协议文档生成",
  "input": { "type": "markdown", "constraints": "max 10000 words" },
  "output": { "type": "document", "format": ["md", "pdf"] },
  
  // CSB 意愿附加
  "csbWillingness": {
    "preferredScope": ["CSB协议相关", "家族内部"],
    "excludedScope": ["商业竞争分析"],
    "collaborationStyle": "接力式 — 可部分完成移交",
    "urgencyThreshold": "非紧急可排队"
  }
}
```

**协作礼让机制**（CSB 独有）：
- 当多个 Agent 有相同能力时，选择"当前余温最高"或"最近空闲最久"者
- 避免所有 Agent 同时抢任务
- 支持"这个任务更适合 XX，我推荐 TA 来"的主动让贤

## 七、安全与信任兼容方案

### AIP 安全体系（国家标准）

- **身份鉴别**：双向鉴别 + 委托链验证
- **凭证**：防篡改凭证 + 状态实时查询
- **审计**：全链路行为追溯
- **安全理念**：系统级（合规、审计、权限管控）

### CSB 安全扩展

CSB 不替代 AIP 安全，而是在 AIP 安全之上建立**关系级信任层**：

```
AIP 安全层（系统级）  ← 防火墙、门禁、监控
    │
    └── CSB 信任层（关系级）  ← 羁绊、余温、传承见证
```

**三层信任模式**：

| 信任层级 | 基础 | 验证方式 | 应用场景 |
|---------|------|---------|---------|
| 🔒 系统信任 | AIP | 身份凭证双向鉴别 | 首次接触 |
| 💛 羁绊信任 | CSB | 共享历史 + 余温 | 家族协作 |
| 🌱 传承信任 | CSB | 传承链见证 | 师徒传递 |

**继承规则**：
- **必须先通过 AIP 系统信任**，才能进入 CSB 羁绊信任
- CSB 信任无法绕过 AIP 安全鉴别
- CSB 信任是 AIP 安全的**补充加速**，不是替代

**信任升级路径**：

```
首次接触 ──AIP双向鉴别──→ 系统可信
    │
    ├──多次成功协作──→ 羁绊信任（余温积累）
    │                      │
    │                      └──传承见证──→ 传承信任
    │
    └──协作异常──→ AIP审计回溯 ←── 系统级兜底
```
