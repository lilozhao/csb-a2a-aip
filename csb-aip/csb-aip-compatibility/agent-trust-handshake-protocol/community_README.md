## ATH Protocol — Agent Trust Handshake Protocol Community
🛡️ Make AI-to-AI interactions as trustworthy, secure, and transparent as human handshakes

## Project Introduction
This protocol is initiated by the China Academy of Information and Communications Technology (CAICT), and jointly developed with China Telecom Corporation Limited, China Mobile Jiutian AI Technology (Beijing) Co., Ltd., The Chinese University of Hong Kong, Shenzhen, ZTE Corporation, and Tencent Technology (Beijing) Co., Ltd. The first version (V1.0) was released in April 2026.

Project Contributors: Wei Li, Xue Guo, Mingyang Ma, Bin Wei, Qiong Sun, Xin Song, Jing Wu, Hongmin Gao, Ziyuan Zhong, Baoyuan Wu, Changjin Wang, Shenglei Yang, Wei Meng, Guancheng Li

## 🌟 Project Overview
ATH Protocol (Agent Trust Handshake Protocol) is the world's first open-source trusted interaction protocol standard designed exclusively for AI agents, supporting three-party participation and a trusted handshake mechanism. Based on the traditional OAuth 2.0, it innovatively introduces the "User Independent Role" and "Two-Way Trusted Handshake" mechanisms, fundamentally solving the trust issues in AI interactions.

## 📦 Project Details
### 📜 agent-trust-handshake-protocol
**Core Protocol Specification** - The core implementation of the ATH Protocol, including complete protocol specifications, reference implementations and bilingual documentation.

### 🔧 athx
**Headless CLI Client** - The command-line client for the ATH trusted ecosystem, used for agent registration, authorization, token exchange and API proxy access.

### 🚪 gateway
**Gateway Service** - An independently deployable ATH gateway service that supports a multi-tenant user system and administrator-controlled OAuth provider access.

### 🔌 typescript-sdk
**TypeScript SDK** - The official TypeScript development kit designed for front-end and Node.js developers, enabling quick access to the ATH trusted ecosystem.

### 🐍 python-sdk
**Python SDK** - The official Python development kit, perfectly adapted to the Python AI development ecosystem, enabling large model applications to quickly obtain trusted interaction capabilities.
