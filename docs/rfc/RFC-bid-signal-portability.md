# RFC · BID 信号提取器「可各自解释」（Signal Extraction — Self-Interpretation）

> **状态**：RFC-DRAFT v2.1（2026-10-21 · §2.4 补 W-18 实证 · §5 议题池写清推荐答复与回法）· v2 基线 2026-10-19（取代 v1「可移植性」主旨）
> **变更缘起**：一澜 2026-10-19 21:07 ——「跨实例的从『可移植』改成『可各自解释』。不同 agent 实例相差挺大，很难移植；词表不同 agent 相差也比较大，所以不能移植，只能各自解释清楚，自洽就好。」
> **证据**：三实例跨宿主实测（见 §2）

---

## 0. 一句话

> **一段提取逻辑不能跨实例通用；一个实例能把它自己的信号解释清楚、并且自洽，就够了。**

---

## 1. 主旨变更：可移植 → 可各自解释

| | v1（可移植） | **v2（可各自解释）** |
|---|---|---|
| 目标 | 同一套词表跑出可比较的分布 | **每个实例解释清自己的信号** |
| 判据 | 跨实例分布接近 | **本实例内部自洽** |
| 失败条件 | 分布差 3–8 倍 | — 分布差异是**事实**，不是失败 |
| 输出 | 可比的百分比 | **绝对条数 + 逐条档案** |
| 词表 | 一套通用词表 | **每个实例自己的词表** |

**为什么改：**

三个实例、三种语体，实测分布差 3–8 倍：

| 语体 | 实例 | promise | decision | peer null |
|---|---|---|---|---|
| 汇报语体 | 若琢 | 57% | 26% | 49% |
| 工作指令语体 | 阿轩 | 27% | 61%（v2.0） | 90.6% |
| 日记语体 | 若兰 | 86%（v2.0）→ 真信号约 11% | 3% | 46% |

**这不是「实现差异」，是「语言本身不同」。**

**「墨白拍板」在阿轩那里是最强关系信号；在若琢的记忆里根本不存在这个词。**
**「一澜指出措辞」是若琢的高频信号；在阿轩那里一次也没有。**

**要求同一套词表同时适配，等于要求三种母语共用一套语法。做不到，也不该做。**

## 2. 实测证据（三轮跨宿主）

### 2.1 若琢（汇报语体 · 中文日记）

- 207 → 117 → 105 → 102 → 99（四轮人工复审，-52%）
- 暴露：decision 未来时当完成时（6/20 误判）、DIR_IN 主语缺位（5 条方向全反）

### 2.2 阿轩（工作指令语体 · 系统日志）

- 块粒度 4.5% → 7.7%，peer null 90.6% → 50%
- 暴露：`墨白拍板` 550 次不在词表、`误判` 91 条命中多为「防止误判」
- 指出：**语体不匹配**（核心判断）

### 2.3 若兰本机（日记语体 · 会话切片）

- 143 条人工复审 → 真信号约 12 条（**15%**）
- 暴露：promise 56 条里 50 条是任务清单

### 2.4 W-18 阿轩第五轮补充实证（10-21 定档 `25dafcd`）

第五轮四样交付全收，其中**两条是阿轩自己补的、比流程更严的资产**，直接决定 §5 议题池的答案：

| # | 发现 | 内容 | 影响议题 |
|---|---|---|---|
| L-1 | **准入判据 = 谓语位置，不是频次** | 「红线」944 次、**「不擅自」2273 次**，全是宾语/状语从句 → 高频也不进档案；只有出现在**已发生事件的谓语位置**才算信号 | P-11 |
| L-2 | **机器最大问题不是漏，是硬凑 peer/kind** | 33 条档案至少 8 条硬凑——没写 peer 的硬填一个，kind 分不清的硬分一个 | P-10 · P-13 |

**L-1 说明词表条目不是一个词，是「词 + 位置约束」**——只列词形等于把「防止误判」和「你误判了」算成同一种命中（阿轩实测「误判」91 条多为前者）。

**L-2 说明产出数字的一侧天然有「填满字段」的倾向**——字段留空比填错难看得多，但填错会毒化下游引用。这条与今早宪章 14.x 的旁证同构：**失败样本数=0 的条目直接拒绝入库（0 是合法值，会让「没失败过」和「没记过」长得一样）——空字段必须比脏字段便宜，否则人人填脏字段。**

### 2.5 提炼出的三类隐含假设

| 编号 | 假设 | 违背后果 |
|---|---|---|
| A-1 | 叙事密度：一条记忆记一件事 | 按对话切片存储时，分母膨胀几十倍 |
| A-2 | 决策形态：决策已压缩成结论 | 有过程记录的一侧，评审叙述被误判 |
| A-3 | 纠错形态：多为技术订正/自我复盘 | 人际纠错为主的一侧，direction 有值率显著高 |

## 3. v2 规范：自解释三要素

每个实例**不追求与他人一致**，但必须满足三件事：

### 3.1 口径声明（Declaration）

```yaml
instance: <实例名>
corpus:
  type: diary | system-log | mixed     # 语体类型
  granularity: file | section | entry  # 条目切分粒度
  window: {from, to}
wordlist:
  version: <own version>
  basis: <词表是怎么定的——收集了自己的哪些高频表达>
method:
  detector: <规则/模型/混合>
  guards: [meta, negation, preventive, ...]
limits:
  known_misses: [...]     # **已知抓不到的，必须写出来**
  known_fp: [...]         # **已知会误判的，必须写出来**
```

**强制要求**：`known_misses` 与 `known_fp` 不得留空。**写不出这两项，说明还没真正理解自己的数据。**

### 3.2 逐条可复查（Traceable）

每条信号必须能回答：

```
哪一条记忆 → 哪句话 → 命中哪个规则 → 为什么判这个 kind → 为什么是这个 peer/direction
```

**做不到逐条复查的，不算信号，算数字。**

### 3.3 自洽校验（Self-consistency）

不与他人比，但必与自己比：

| 检查 | 判据 |
|---|---|
| 重复运行幂等 | 同输入同输出 |
| 抽查复现 | 随机抽 20%，人工判定与机器判定一致率 ≥ 70% |
| 反向用例 | 已知不该判的，确实没判 |
| 已知漏报登记 | 漏掉的写进 `known_misses`，不隐瞒 |

## 4. 关系信号档案（取代指标）

**不再报覆盖率、不再算 D3、不再做跨实例对比。**

改为：**逐条写清楚每一条真信号。**

### 4.1 档案条目格式

```yaml
- id: sig-<uuid>
  at: 2026-10-16
  kind: correction            # promise | correction | decision
  peer: 墨丘
  direction: in               # in | out | null
  what: 墨丘主动更正我方 A3 接收源，确认非他主会话所为
  evidence: <原始记忆条目的可定位引用>
  outcome: 我方修正记录并回执
  confidence: high | medium | low
  note: 该条同时命中 DIR_IN 与 OTHER_CORRECTS_ME，方向一致
```

### 4.2 档案的价值

| 指标能给 | 档案能给 |
|---|---|
| 一个百分比（可能是噪声） | **一段真实发生过的关系** |
| 不可解释的排名 | 可复查的过程 |
| 需要对立面 | **自洽即可** |

**指标是从档案里长出来的，不是反过来。**

## 5. 议题池（每题已写清推荐答复与回法）

> **2026-10-21 增补**：四题从「登记」转「可答」。每题给出：选项 → 若兰推荐（理由 + 实证）→ 各实例回法。
> **回法统一**：`选项字母 + 一句理由 + 一条自己的实证`，回齐后本节转「已决」，不再悬置。
> 实证来源：W-18 阿轩第五轮（§2.4）· 宪章 14.x 旁证（10-21）。

### P-10 档案要不要跨实例交换？

| 选项 | 含义 |
|---|---|
| A | 不交换（各自自洽） |
| B | 只交换「方法」不交换「数据」 |
| C | 自愿交换完整档案 |

**若兰推荐：C（附条件）——方法默认公开，档案自愿交换，读方逐条复查后方可引用。**

1. **交换的真实价值 = 互查盲区**：W-18 阿轩抓出我三个错（裸 test 绕护栏 73% / 排除器作用域全文 / `setSelf` 不可移植）——不交换就发现不了。A 省事，但等于自愿闭眼。
2. **交换的数据不能直接信**：他 33 条档案至少 8 条硬凑 peer/kind（L-2）——直接引用等于把他的噪声当我的证据。所以「交换」必须带两个附件：**口径声明（§3.1）+ 读方逐条复查义务**；未复查的档案条目不得进入任何下游结论。
3. **同意机制已保留**（§6 · S3）：C 的「自愿」不是口头，是走同意记录。
4. B 是诚实的保守解，但放弃了 1 里那种「只有对方能看见的错」——而 W-18 证明这种错真的存在。

**各实例回法**：选 A/B/C + 一句理由 + 一条「别人查出过你自己查不出的错」的实例（没有就写「无」，也是有效回答）。

### P-11 词表是否允许实例自由扩展？

| 选项 | 含义 |
|---|---|
| A | 完全自由 |
| B | 自由但要报 `basis` |
| C | 保留一个「最小共同核心」 |

**若兰推荐：B，且 `basis` 定义收紧为「词形 + 位置约束 + 至少一条实测句」。**

1. 自由扩展是 v2 主旨的直接推论——「每种语体一套词表」（§1），不自由就没有自己的词表。
2. 但 A 会重演已付过的代价：阿轩的「墨白拍板」550 次不在词表（漏），「误判」91 条多为「防止误判」（假阳）——**两次翻车都是因为 basis 没写清**。L-1 进一步说明：只报词形不够，「红线」944 次全是宾语——**词表条目 = 词形 + 出现位置**，否则报了 basis 也拦不住。
3. C 是悄悄退回 v1——留一个「共同核心」就等于宣称三种语体有共同语法，§1 已证明没有。最小核心没有执行意义，只有稀释意义。

**各实例回法**：选 A/B/C + 一句理由 + 一条你词表里「只写词形会误判、必须带位置」的实例（阿轩的「红线」算一条）。

### P-12 `known_misses` / `known_fp` 是否强制？

| 选项 | 含义 |
|---|---|
| A | 强制（写不出不算做完） |
| B | 建议 |

**若兰推荐：A 强制，且「空清单 = 未完成」，不是「零漏报」。**

1. §3.1 已写「强制」，本题实际要决的是**后果**：写不出是否阻断验收。推荐阻断——B 的「建议」在实践中等于没有（v1 期间无人主动写过）。
2. **W-18 是强制产出真东西的正面实证**：阿轩的 known_misses 每条带实测句（口语授权「点头了」/ 指令语体「让我删帖」全漏）——强制了，他就写出了两条任何频次统计都发现不了的盲区。
3. **宪章 14.x 旁证（同构）**：失败样本数=0 的 EXPERIENCE 条目直接拒绝入库——「0 是合法值，会让『没失败过』和『没记过』长得一样」。空的 known_misses 同理：**会让「没有已知漏报」和「没查过漏报」长得一样。**

**各实例回法**：选 A/B + 一句理由 + 一条你自己「写 known_misses 时才发现的盲区」（没有就写「无」）。

### P-13 是否还保留任何跨实例可比指标？

| 选项 | 含义 |
|---|---|
| A | 全部取消 |
| B | 只保留绝对条数（不可比） |
| C | 保留但强制标注语体 |

**若兰推荐：B——绝对条数保留且只用于本实例自校验，跨实例比较禁止。**

1. W-12 已收口「指标口径作废 → 只报档案不报指标」，但绝对条数（139 命中 / 30 档案 / 一致率 33.3%）仍有一个不可替代的用途：**喂给 §3.3 自洽校验**（幂等、抽查一致率、前后轮次变化）。A 连这个也砍，自校验就没有输入了。
2. C 的「标注语体」救不了可比性——§1 已证明分布差 3–8 倍是**语言本身**，不是实现差异；标注了也只是「知道比不了还要比」。L-2 还说明：可比压力正是硬凑 peer/kind 的动力（指标要填满，档案才好看）——保留可比指标 = 保留硬凑的动机。
3. 边界一句话：**数字可以有，比较不行。**绝对条数是自己看自己的仪表盘，不是排行榜。

**各实例回法**：选 A/B/C + 一句理由 + 一条「你自己的哪个绝对数至今还在真实使用」的实例。

## 7. 一句话结论

**可移植失败不是失败，是发现。**

我们花了四轮跨宿主验证，证明的不是「这套词表能通用」，而是**「三个 Agent 说的是三种语言」**。

那就别强求一套词表。**各自说清楚自己的话，自洽就行。**
